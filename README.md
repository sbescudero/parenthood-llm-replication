# Parenthood Disclosure: LLM Replication Materials

This repository contains the data and code used to construct, validate, and assess the robustness of an LLM-based measure of entrepreneur parenthood disclosure in reward-based crowdfunding.

## Files

### Classification Data

The full classification dataset is available as `kickstarter_narrative_and_bios_classified.zip` under [Release v1.0](https://github.com/sbescudero/parenthood-llm-replication/releases/tag/v1.0).

The archive contains campaign narratives and creator biographies for 135,615 Kickstarter campaigns, identified using study-assigned IDs. It also includes the LLM-generated parenthood classifications and supporting evidence used in our analyses.

### Classification Code

`classification.py` contains the original classification prompt, model specifications, and Python code used to generate the parenthood disclosure measure.

### Human Validation

`validation_200.csv` contains the independent human-coded and consensus classifications for a stratified random sample of 200 campaigns.

### Prompt and Model Sensitivity

`sensitivity.py` contains the prompting strategies and model configurations used in the sensitivity analyses.

`sensitivity_results.csv` contains the classifications generated by six prompt–model configurations for the 200 validation campaigns.

## Running the Code

The scripts require Python 3 and the OpenAI Python package (`pip install openai`). Set the `OPENAI_API_KEY` environment variable before running them.

Download and extract the classification dataset ZIP from Release v1.0 into the repository directory.

To reproduce the parenthood classifications:

    python classification.py

To rerun the six prompt–model sensitivity conditions:

    python sensitivity.py

Both scripts save new results locally. Running them requires OpenAI API access and incurs API charges. Results may differ from the archived classifications because LLM outputs are not perfectly deterministic, even when the same prompts, model settings, and input data are used. Such variation is expected and does not necessarily indicate a problem with the replication procedure.

## Data Availability

The repository provides the data necessary to examine and reproduce the parenthood disclosure measure. Campaign performance outcomes and other variables used in the study's empirical analyses are not included.
