# Parenthood Disclosure: LLM Replication Materials

This repository contains the data and code used to construct, validate, and assess the robustness of an LLM-based measure of entrepreneur parenthood disclosure in reward-based crowdfunding.

## Files

### Classification Data

`kickstarter_narrative_and_bios_classified.csv` contains the campaign narratives and creator biographies for 135,615 Kickstarter campaigns, identified using study-assigned IDs. The file also includes the LLM-generated parenthood classifications used in our analyses and their supporting evidence.

### Classification Code

`classification.py` contains the original classification prompt, model specifications, and Python code used to generate the parenthood disclosure measure.

### Human Validation

`validation_200.csv` contains the independent human-coded and consensus classifications for a stratified random sample of 200 campaigns.

### Prompt and Model Sensitivity

`sensitivity.py` contains the prompting strategies and model configurations used in the sensitivity analyses.

`sensitivity_results.csv` contains the classifications generated by six prompt–model configurations for the 200 validation campaigns.

## Reproducibility

Classification was conducted using GPT-5.2. Sensitivity analyses compared role-based zero-shot, few-shot, and Chain-of-Thought prompting across GPT-5.2 and GPT-5 mini.

The Python scripts document the prompts, model settings, and procedures needed to reproduce the classifications. Re-execution requires access to the relevant models through the OpenAI API, and outputs may vary across runs.

## Data Availability

The repository provides the data necessary to examine and reproduce the parenthood disclosure measure. Campaign performance outcomes and other variables used in the study's empirical analyses are not included.
